# 🏭 Industrial AI & Fault Diagnosis

Research hub for **industrial computer vision, intelligent fault diagnosis and condition monitoring**, maintained as part of Dr. Fahmid Al Farid's academic GitHub portfolio.

## Focus
- Wafer-map defect classification
- Bearing and machinery fault diagnosis
- CNN/Transformer hybrid architectures
- Time-frequency and spectrogram-based diagnosis
- Industrial condition monitoring
- Explainable and efficient industrial AI
